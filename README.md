# SUHANA.N — Python Developer Portfolio

A responsive, modern developer portfolio tailored for **Python Developer** applications, built from SUHANA.N's resume.

## Files

- `index.html` — Semantic portfolio structure (Hero with interactive Python terminal/CLI, About, Skills, Experience Timeline, Filterable Projects + Architecture Modal, Education & Languages, Contact).
- `styles.css` — Dark/Light theme styling, responsive grid layouts, glassmorphism cards, syntax-highlighted terminal styling, and print styles.
- `script.js` — Interactive terminal tabs & CLI REPL, typing animation, project category filters, project details modal, copy-to-clipboard actions, and mailto draft composer.

## Quick Local Preview

Run a local static server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Free Hosting on GitHub Pages

1. Create a repository on GitHub (e.g., `suhana961.github.io` or `portfolio`) under `https://github.com/suhana961`.
2. Push `index.html`, `styles.css`, and `script.js` to the `main` branch.
3. Enable **Settings -> Pages -> Deploy from branch (`main` / root)**.
4. Optionally update the project `GitHub` links in `index.html` from `https://github.com/suhana961` to each project's specific repository URL.
